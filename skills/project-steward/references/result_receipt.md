# 結果受領と一覧反映

既存依頼の結果受領と、許可された浅い一覧反映に使う手順です。

1. 今回の依頼と対応する、空でない結果本文を確認して受領する。取得画面が空でも保存本文の不存在とは扱わない。空本文を一度再確認しても得られなければ、独立した読み取り確認または障害連携へ進み、同じ依頼を無制限に繰り返さない。
2. 受領本文を根拠に、許可された一覧の古い受領状態・現在地を浅く同期する。担当の報告と独立検証を区別する。別事項、未確認の意味・判断・日付を根拠なく変更しない。
3. 本文受領、一覧反映、元事項自身の完了を区別する。結果に未解決が残る場合は完了にせず、残る内容、次の行動、戻る条件を元事項へ保つ。関係する別事項の完了へ広げない。
4. 保存後に一覧を読み戻す。保存できなかった処理を反映済みとしない。その状態を踏まえ、[結果返却](result_return.md)に従ってOwnerへ返す。
