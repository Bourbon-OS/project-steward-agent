このパッケージは、Project Steward Agent 構想のドキュメントのみを切り出した公開用資料です。

目的は、会社固有の開発成果や業務上の資料が混ざる前に、中核となる考え方、要件、設計方針、MVP スコープを、オープンな文化的・技術的パターンとして公開可能な形で固定することです。

## 含まれるもの

- `docs/concept.md`: 中核コンセプトと "Keep the Ashiba" の考え方。
- `docs/requirements.md`: 初期 MVP 要件。
- `docs/design.md`: 設計メモと役割境界。
- `docs/mvp_plan.md`: 実装前の MVP スコープ整理。
- `docs/index.md`: 読む順番。
- `LICENSE.md`: CC BY 4.0 のライセンス表記。
- `NOTICE.md`: 公開範囲、非独占の意図、出典表示の方針。

## 含まれないもの

この公開版には、次のものを意図的に含めていません。

- プログラムのソースコード
- テストコード
- プロンプト
- ローカルのエージェント設定や skill ファイル
- 生成済みプレゼン資料
- 調査メモや第三者ツール比較メモ
- 会社固有、顧客固有、または機密性のある情報

これらの除外ファイルは私的な開発では有用な場合がありますが、最初の公開ドキュメント版には不要です。
