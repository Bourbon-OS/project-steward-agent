# Project Steward Agent

**公開状態:** v0.2（docs-only）

> 文脈が消える前に。消えた後にも、戻れるように。

変更した理由は、その時は分かっていても、時間がたつと簡単に失われます。数か月ぶりにプロジェクトを開いたとき、何を変更したかはGitに残っていても、なぜ変えたのか、何に依存しているのか、次にどうするのが安全なのか分からなくなることがあります。プロジェクトは、動いているだけでは健全とは限りません。

このプロジェクトでは、変更時に渡された文脈を受け取り、定期的な軽い見回りで漏れを拾うAIエージェント「Project Steward Agent（PSA）」を設計しています。

現在の公開版はドキュメントのみです。実行可能なエージェントやコードは、まだ含まれていません。

PSAは、既存のGitや管理方法を置き換えません。残された痕跡を先に調べ、事実・推測・不明点を分け、重要な判断を人間へ残します。人の指示と許可を受けた後は、助言だけで終わらず、記録や修復まで行うことを目指します。
